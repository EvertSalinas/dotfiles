# Arch/Omarchy equivalent of the Brewfile. One package per line, "#" lines are comments.
# Official: awk '/^\[official\]/{f=1;next} /^\[/{f=0} f&&!/^#/&&NF' packages-arch.txt | sudo pacman -S --needed -
# AUR:      awk '/^\[aur\]/{f=1;next} /^\[/{f=0} f&&!/^#/&&NF' packages-arch.txt | yay -S --needed -
# [official] = Arch repos + the Omarchy repo (omarchy*, mise-bin, ghostty, spotify, nordvpn-bin...).
# Every name was verified with `pacman -Si` / `yay -Si`; listed names match the installed ones so --needed
# never tries to swap a package for a conflicting variant (e.g. mise-bin, not mise).
# Mac-only items intentionally absent: reattach-to-user-namespace, cocoapods, mole, orbstack, alacritty, rar, chromedriver, acli.
# Not installable from a repo/AUR: qbz-bin (built locally from https://github.com/vicrodh/qbz).
